# Where's the Ground?

Jogo de plataforma 2D feito em HTML, CSS e JavaScript.

Para jogar localmente: `python -m http.server 8000` e abra `http://localhost:8000`.

**Controles:** A/D para mover, Espaço para pular/voar e Shift para impulso.

**GitHub Pages:** em Settings → Pages, selecione **GitHub Actions**. O jogo será publicado a cada push na `main`.
