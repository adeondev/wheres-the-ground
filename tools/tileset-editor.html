COMO ME PASSAR ESSE CENÁRIO

O JSON conta a história de cada peça.

  1. Selecione um recorte e preencha nome, função e colisão.
  2. Use Colocar peça para montar o cenário. Selecionar / mover permite arrastar.
  3. Exporte a metadata e coloque o JSON junto do tileset. Me mande o arquivo ou o caminho.

O exemplo é uma interpretação inicial da sua referência. As colisões são editáveis. O personagem no PNG serve como referência de tamanho.

Rascunho salvo neste navegador. O JSON é o arquivo para guardar e compartilhar.
